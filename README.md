## 👋 About Me

I’m **Miftah**, a junior developer learning how to build **real AI-powered systems**, not just notebooks.

I started with **Data Science and Machine Learning** — training models, analyzing financial data, and working on risk-related problems.  
Over time, I realized something important:

> A model is only useful if people can actually use it.

So now I’m focused on **backend development**, **APIs**, and **AI systems** — learning how to connect models to real applications.

I’m still junior.  
Most of my projects are learning-driven.  
But every repo here represents **something I actually built and understood**.

## 📂 Projects I’ve Built While Learning

> These are **learning projects**, not production startups.  
> Each one taught me something specific.

### 🧠 RAG Complaint Intelligence Platform
**Topic:** NLP • RAG • Financial Data  
Built a system to analyze large volumes of financial customer complaints and query them using natural language.  
Learned about vector storage, document chunking, and retrieval logic.

---

### 💳 Credit Risk Scoring ML Pipeline
**Topic:** Fintech • Machine Learning  
End-to-end ML pipeline to predict default risk using RFM features.  
Helped me understand feature engineering and evaluation in real datasets.

---

### 💎 Insurance Claims Intelligence
**Topic:** Risk • Explainable AI  
Built an ML system for insurance pricing with SHAP-based explanations.  
First time working seriously with **model interpretability**.

---

### 📱 Fintech Mobile CX Analytics
**Topic:** NLP • Data Engineering  
Scraped and analyzed Google Play reviews of Ethiopian banking apps.  
Learned sentiment analysis, text preprocessing, and insight extraction.

---

### 📈 Stock Sentiment Analysis
**Topic:** NLP • Finance  
Analyzed financial news sentiment and compared it with stock movements.  
Good lesson in **correlation vs causation**.
