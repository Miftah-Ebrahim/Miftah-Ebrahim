## 👨‍💻 About Me

Most developers focus entirely on the codebase. Most analysts focus entirely on the spreadsheets. I operate in the space between. 

Currently pursuing dual degrees in **Computer Science** and **Business Administration**, I build the backend infrastructure that makes data actually useful. I specialize in Applied AI and workflow automation—writing the Python pipelines that scrape unstructured web data, configuring the vector databases that store it, and architecting the API integrations that allow businesses to interact with it seamlessly. 

I am focused on building autonomous, end-to-end systems that are architecturally sound and practically valuable.
